# Student Performance Analysis using Python and SQL

## Project Overview

This project analyses student academic performance
using Python, Pandas, SQL and SQLite.

The main objective is to understand student performance,
calculate average marks, assign grades and identify
academic trends.

## Technologies Used

- Python
- Pandas
- SQL
- SQLite
- Matplotlib
- VS Code

## Project Features

1. Data cleaning using Pandas.
2. Exploratory Data Analysis (EDA).
3. Calculation of total and average marks.
4. Student grading and ranking.
5. SQLite database creation.
6. SQL queries for data analysis.
7. Data visualisation using Matplotlib.

## SQL Operations

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- COUNT
- AVG
- MAX
- MIN
- SUM
- Subqueries

## Visualisations

Four charts are generated:

- Subject-wise average marks
- Student-wise average marks
- Grade distribution
- Student attendance analysis

## Project Files

- students.csv: Original dataset
- cleaned_students.csv: Cleaned dataset
- student_analysis.csv: Analysis results
- final_student_report.csv: Student grades and rankings
- main.py: Data cleaning and analysis
- database.py: SQLite database creation
- sql_analysis.py: SQL query analysis
- visualization.py: Chart generation
- charts/: Generated visualisations

## Conclusion

This project demonstrates basic data analysis,
database management, SQL querying and data
visualisation using Python.
